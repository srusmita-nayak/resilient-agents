1. Introduction & Executive Summary

Modern multi-agent AI frameworks (AutoGen, CrewAI, LangGraph, ChatDev) operate under an unstated assumption: they assume underlying network channels are completely reliable. In distributed deployments, however, real network channels suffer from packet drops, high jitter, out-of-order delivery, and temporary network partitions.

When unassisted multi-agent workflows encounter network faults, two catastrophic failure modes occur:

  • Deadlock / Hanging: Agents freeze at synchronous round barriers waiting for lost messages that never arrive.
  • State Divergence / Invalidation: Agents make constraint decisions based on stale, missing, or scrambled peer state.

The 5-Line "Project in One Minute" Summary

  • The Problem: Unreliable network channels cause distributed multi-agent reasoning to deadlock or diverge.
  • The Benchmark: Distributed Graph Colouring with mathematically planted zero-conflict solutions.
  • The Solution: Protected Middleware (Mode C) managing ACKs, exponential retries, monotonic versions, and snapshot healing.
  • Experimental Rigor: 600 total database runs across 5 empirical sweeps comparing Modes A, B, and C on identical seeds.
  • The Finding: Protected Mode C eliminates deadlocks (0 deadlocks) and achieves up to 93.3% valid solutions under 50% packet loss where Mode A collapses to 3.3%, at an empirical 2.0x to 5.4x message overhead.
Analogy: The Dinner Party Seating Committee
Imagine three event planners—Alice, Bob, and Charlie—in separate offices coordinating guest seating across wedding tables so that feuding guests never sit together. Every ten minutes (a round), each planner mails their updated seating choices via an unreliable courier.

• Mode A (Strict Baseline): Alice refuses to start Round 2 until she receives postcards from both Bob and Charlie. If Charlie's card is lost in the rain, Alice sits frozen at her desk forever (Deadlock).
• Mode B (Timeout Baseline): Alice sets a timer. If Charlie's card hasn't arrived when it dings, Alice assumes Charlie made no changes and moves forward. She avoids freezing, but might place feuding relatives together (Constraint Conflict).
• Mode C (Protected Protocol): Every card has a sequence stamp. Bob sends back a receipt slip immediately. If Alice gets no receipt within 3 minutes, she re-sends with exponential patience. When duplicate cards arrive, Bob discards the spare. If a road is blocked for an hour, Alice and Bob reconcile master guestbooks the moment it reopens.

2. Core Concepts Explained from Scratch

Every fundamental distributed systems concept in this project is defined below in plain terms:

  • Agent: An autonomous software entity responsible for assigning colors to a subset of graph nodes.
  • Multi-Agent System (MAS): Multiple independent agents cooperating to solve a global problem where knowledge is decentralized.
  • Message: A structured JSON datagram carrying a unique ID, protocol kind, sender, receiver, round, and payload.
  • Packet Loss: A network fault where a message is permanently destroyed in transit and never delivered.
  • Latency & Jitter: Message transit delay and random variations in transit delay.
  • Out-of-Order Reordering: A later message arriving before an earlier message due to channel variations.
  • Duplicate Packets: A single sent packet generating multiple delivery events.
  • Network Partition: A total communication blackout between agent subsets during a specific time window.
  • Acknowledgment (ACK): A receipt packet sent back to the sender confirming successful delivery.
  • Timeout: A countdown deadline after which an agent stops waiting and triggers a fallback or retry.
  • Exponential Backoff: Progressively multiplying retry wait times (e.g. 1.5x) to avoid network congestion.
  • Duplicate Suppression: Inspecting message IDs to discard duplicate deliveries of previously processed messages.
  • Monotonic Versioning: Incrementing integer version numbers on state updates so older updates cannot overwrite newer ones.
  • Snapshot Reconciliation: Exchanging authoritative state digests to repair divergence after network partitions.
  • Deadlock: A frozen state where agents are waiting for messages, but the simulation queue is completely empty.
  • Discrete-Event Simulation ($u$): Tracking time in virtual units ($u$) using a priority queue rather than physical CPU sleep, enabling reproducible millisecond runs.
  • Independent Validator: An isolated module with zero agent dependencies that evaluates the global graph for edge conflicts.

3. The Benchmark Task: Distributed Graph Colouring

Distributed Graph Colouring (DCR) was chosen because it is an NP-complete constraint problem with an unambiguous mathematical verification standard: either two connected nodes share the same color (violation), or they do not.

Nodes are partitioned among agents. Edges connecting nodes owned by the same agent are internal edges. Edges connecting nodes owned by different agents are boundary edges. Boundary edges strictly require network message exchange.

4. The Multi-Agent System Architecture

Implemented in backend/app/agents/base.py:

  • Coordinator (Agent 0): Manages barrier checks and initiates post-partition state syncs (SYNC_REQ).
  • Solvers (Agent 1, Agent 2, etc.): Worker agents evaluating boundary conflicts, proposing recolorings, and sending updates and sync responses.

Decision Policy (DSA-B Heuristic): In each round, each agent counts conflicts for its owned nodes. If conflicts exist, it computes the color minimizing conflicts and moves with probability $p = 0.8$. Stochastic gating prevents oscillatory recoloring cycles between neighboring peers.

5. The Simulated Channel & Fault Injection Engine

All 600 multi-seed research sweeps run on the VirtualChannel (backend/app/core/channel.py) driven by the DiscreteEventScheduler (backend/app/core/clock.py). This provides 100% deterministic reproducibility based on seed.

Localhost Physical UDP Transport Status

A functional physical UDP transport implementation is provided in backend/app/core/transport_udp.py and verified by 5 unit tests in backend/tests/test_transport_udp.py. It provides real socket binding on 127.0.0.1, packet serialization, background receiver loops, and transmission latency tracking. Multi-machine physical WAN/LAN deployments remain future work.

Guarantees vs Non-Guarantees: Mode C guarantees at-most-once application and stale invalidation freedom. It does not claim impossible exactly-once delivery across broken networks; if retries are exhausted, it degrades gracefully to keep agents moving.

15. Limitations, Disclosures & Threats to Validity

  • Deterministic Agents: All 600 stored runs used deterministic DSA-B agents. Zero empirical runs used live Gemini LLMs.
  • Transport Scope: Localhost loopback UDP transport is implemented and unit-tested. Multi-host distributed WAN deployments remain future work.
  • Benchmark Scope: Evaluated on Distributed Graph Colouring; conversational multi-agent dialogue workflows require separate evaluation.
  • Hard Preset Timeouts: Scaling to dense instances requires calibrating round barrier budgets to accommodate backoff retries.
